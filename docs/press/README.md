# Margin of Victory press kit

## One sentence

Margin of Victory is a turn-based election strategy game where players manage
time, money, staff, polling, debates, and events across 49 campaigns in six
countries.

## Availability

- Play the base game free in a browser.
- Two starter scenarios and the daily challenge stay free.
- Optional historical scenario packs are one-time purchases.
- No subscription is required.
